# AmbientFrame —— 手势交互氛围画框

一块 ESP32 驱动的氛围灯画框：**温度决定颜色，靠近决定开关**。

| 模块 | 作用 |
|------|------|
| ESP32-WROOM-32 | 主控 |
| WS2812B RGB 灯带 | 光源，颜色随室温从冷蓝渐变到暖红 |
| DHT11 | 温湿度传感器 |
| 红外避障模块 | 靠近开灯 / 离开熄灭 |
| 0.96" SPI SSD1306 OLED | 显示温湿度与灯光状态 |
| 木质画框 + 硫酸纸 | 柔光 |

## 功能

- 红外避障靠近开灯、离开熄灭（可切换为每次靠近翻转开关）
- 温度 10°C~40°C 映射为灯色：蓝 → 青 → 绿 → 黄 → 红
- OLED 实时显示温度 / 湿度 / 灯光状态
